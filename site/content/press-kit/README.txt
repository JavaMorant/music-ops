Dibsss — Press Kit
==================

Drop your real assets into this folder (content/press-kit/) and they get
bundled into the downloadable press-kit.zip automatically on every build:

  bio.md          - press bio (short + long)
  tech-rider.md   - technical rider
  photos/         - press photos (add .jpg / .png here)
  logos/          - logo files (add .png / .svg here)

This README and the placeholders can be replaced. The zip is regenerated by
`npm run build` (see scripts/build-press-kit.mjs).
